# מה להביא: מדריך המדיה

> הקובץ הזה נוצר אוטומטית מתוך `js/media.js` (הרצה: `npm run media-guide`). כדי לשנות רשימה, עורכים את `js/media.js`.

## איך מכניסים קובץ

1. שומרים את הקובץ בתיקייה `media/` **בדיוק בשם שבטבלה** (כולל תת-התיקייה `img/` או `video/`).
2. מרעננים את המצגת (Cmd+R). כרטיס ה"חסר" מתחלף בתמונה.
3. מקש **M** במצגת מציג טבלה חיה: מה קיים ומה חסר.
4. כל תמונה מ-Commons: רושמים ב-`CREDITS.md` את השם, היוצר, הרישיון והקישור.

**פורמטים:** תמונות `.jpg` (אפשר גם png או webp, אבל אז צריך לעדכן את הסיומת ב-`js/media.js`). רוחב 1600–2400 פיקסלים מספיק. וידאו: `.mp4` (H.264), עדיף בלי סאונד חזק. קטעים קצרים, עד דקה.

**מקום כמו בשקף:** רוב התמונות מוצגות על כל המסך (חיתוך לרוחב 16:9). תמונה לאורך תיחתך. אם חשוב לראות את כולה, הוסף `contain` ל-class של ה-`.m` באותו שקף.

## מה אני (Claude) לא יכולתי להביא, ולמה

- **Wikimedia Commons חסום** מהסביבה שבה עבדתי, כך שלא הורדתי אף תמונה. לכל תמונה מסוג Commons כתבתי מה לחפש. אחרי ההורדה, צריך לבדוק בעמוד הקובץ את הרישיון (CC BY / CC BY-SA / Public domain) ולרשום אותו ב-CREDITS.md.
- **קליפים מוגנים** (Iron Man, ויל סמית, deeptomcruise, צוקרברג): לא הורדתי ולא אוריד בלי אישורך. אם אתה מחליט להקרין, זה קטע קצר, בכיתה בלבד, עם קרדיט על השקף.
- **צילומי מסך מכלים** (AI שמדבר, מצייר, מלחין; פרומפט מעורפל מול מפורט): צריך חשבון ולחיצות, אז זה עליך. ההוראות למטה.
- **לא ייצרתי שום תמונה מזויפת** ולא שמתי "דוגמה" במקום תמונה אמיתית. כל מה שחסר מסומן בבירור על השקף.

## למשחק "אמת או AI?"

- סבבים 2, 4 ו-6 הם תמונות שאתה מייצר בכלי AI. כדאי לבחור דברים יומיומיים שנראים כמו צילום טלפון. ב-`CREDITS.md` רושמים: "נוצר ב-AI על ידי אלי, [כלי], [תאריך]".

- סבב 5 הוא תמונת האפיפיור (מרץ 2023).
- **אם תרצה לשנות את סדר התשובות**, משנים ב-`index.html` את ה-class של `verdict` (`real` או `ai`) ואת הטקסט שלו.
