# הרצאה: בינה מלאכותית (כיתות ז׳-ח׳, לומדים עם מדענים)

מצגת HTML מקומית שעובדת **בלי אינטרנט**. בפנים: 61 שקפים, 7 הדגמות אינטראקטיביות, משחק "אמת או AI?", הערות דובר לכל שקף, ו**מפעל הפרומפטים** לפעילות של התלמידים.

**למה reveal.js?** זו ספריית מצגות HTML ותיקה ויציבה. היא נותנת מוכן ובלי שרת את כל מה שביקשת: חשיפה הדרגתית, חלון הערות דובר עם שעון, סקירה של כל השקפים, מסך שחור, מסך מלא ו-PDF. היא רצה בדפדפן, בלי Keynote ובלי התקנה.

---

## הפעלה (ביום ההרצאה)

**הדרך המומלצת (Mac):** לחיצה כפולה על `start.command`. נפתח Chrome על המצגת.
(בפעם הראשונה macOS עלול לחסום: לחיצה ימנית, אחר כך "פתח", ואחר כך "פתח" שוב.)

**או בטרמינל:**
```bash
cd ai-lecture
npm start            # → http://localhost:8000
```

**בלי Node בכלל:** פותחים את `index.html` ישירות ב-Chrome (גרירה לחלון). בדקתי שגם ככה הכל עובד, כולל חלון ההערות והמקש D. השרת המקומי עדיף רק כי הוא מוודא שהסרטונים נטענים מהר.

> מומלץ **Chrome**. לחבר את המקרן כ**מסך נפרד** (לא שכפול מסך), כדי שחלון ההערות יהיה רק אצלך.

## מקשים

| מקש | מה עושה |
|---|---|
| → / רווח / PageDown / לחיצה על השקף | הבא (כולל החשיפה הבאה) |
| ← / PageUp / לחיצה ימנית | הקודם |
| **S** | חלון הערות דובר: השקף הבא, שעון, זמן שעבר, ההערות |
| **F** | מסך מלא |
| **B** או **.** | מסך שחור (לחיצה נוספת מחזירה) |
| **O** או **Esc** | סקירה של כל השקפים |
| **G** | קפיצה לשקף לפי מספר או שם |
| **D** | הצגה והסתרה של **הקלף האישי** (געגוע לאבא). עובד גם מחלון ההערות |
| **T** | שעון קטן בפינה (שעה, זמן שעבר, מספר שקף). ‏**Shift+T** מאפס |
| **M** | טבלת המדיה: מה קיים ומה חסר |
| **H** | הסתרת כרטיסי "חסר קובץ" מהמסך |
| **?** | רשימת כל המקשים |

**וידאו:** בשקף עם סרטון, הלחיצה הראשונה מנגנת אותו. אפשר גם ללחוץ על הסרטון עצמו כדי לנגן או לעצור. כשעוברים שקף, הסרטון נעצר. אם קובץ הווידאו חסר, הלחיצה הזאת לא "מתבזבזת".

## מבנה

```
index.html          ← השקפים + הערות הדובר (<aside class="notes">)
factory.html        ← מפעל הפרומפטים (קובץ אחד, עומד בפני עצמו, להעלאה לרשת)
js/personal.js      ← התוכן האישי שלך (עורכים כאן)
js/media.js         ← רשימת כל קבצי המדיה: שם, שקף, מה לשים
js/deck.js          ← מנוע: מדיה, קלף אישי, קיר בעיות, טיימרים, מקשים
js/demos.js         ← ההדגמות האינטראקטיביות
css/deck.css        ← העיצוב
media/img, media/video  ← לכאן שמים את הקבצים
vendor/             ← reveal.js, גופנים, QR (מקומי, בלי אינטרנט)
tools/              ← שרת מקומי, בדיקה, PDF, מדריך מדיה
LECTURE_PLAN.md     ← לוח זמנים + מה לדלג אם מאחרים
MEDIA_GUIDE.md      ← מה להביא (נוצר מ-js/media.js)
SOURCES.md          ← מקור לכל טענה
CREDITS.md          ← רישיונות
```

## פקודות

```bash
npm install          # פעם אחת. רק בשביל הבדיקות וה-PDF; המצגת עצמה לא צריכה את זה
npm start            # שרת מקומי בפורט 8000
npm test             # בדיקה בדפדפן אמיתי: כל השקפים וכל החשיפות ב-5 גדלי מסך, המקשים וההדגמות
SHOTS=1 npm test     # כנ״ל + צילום מסך של כל שקף ל-test-shots/
npm run pdf          # PDF גיבוי → ai-lecture.pdf (שקף לעמוד, עם כל החשיפות)
npm run media-guide  # מעדכן את MEDIA_GUIDE.md לפי מה שקיים בתיקיית media/
```

אם `npm test` או `npm run pdf` לא מוצאים דפדפן: `npx playwright install chromium`. אפשר גם לכוון ל-Chrome שלך עם `CHROME_PATH=...`.

## מפעל הפרומפטים (`factory.html`)

קובץ HTML אחד, בלי ספריות ובלי שרת. התלמידים עונים על 7 שאלות: מי אני, מטרה, תוכן, סגנון, יכולות, אילוצים, דוגמה. בתמורה הם מקבלים פרומפט מפורט, עם **מד איכות** וטיפים לשיפור.
- **לא שולח שום מידע.** התשובות נשמרות רק בדפדפן של התלמיד (כדי שלא יימחקו ברענון).
- **מסנן מידע אישי:** טלפון, מייל, ת״ז, כתובת או סיסמה נמחקים עם אזהרה. בשדה הכינוי יש אזהרה על שם מלא.
- **כדי שתלמידים יגיעו אליו**, צריך לשים אותו ברשת (למשל GitHub Pages) ולעדכן את `factoryUrl` ב-`js/personal.js`.
